# Shalih Shoes

A production-ready thrift footwear marketplace for Pakistan — pre-loved sneakers and chappals with a trust-first, mobile-first shopping experience.

## Overview

Shalih Shoes is a curated e-commerce platform for authenticated pre-loved international footwear. The storefront is built to feel premium and credible (GOAT/StockX-inspired), with transparent condition grading, local payment flows, and fast performance on mobile networks.

**Status:** In active development (MVP)

## Stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui |
| Backend | FastAPI, PostgreSQL, Redis |
| Hosting | Vercel · Koyeb · Neon |

## Features (MVP)

- Editorial homepage and product catalog with filters
- Product detail pages with condition grading and real photography
- Cart and checkout (Cash on Delivery + Bank Transfer)
- User accounts, order history, and tracking
- Admin panel for inventory and order management

## Project Structure

```
/app          Next.js storefront and admin routes
/components   Reusable UI components
/lib          API clients, stores, types, utilities
/backend      FastAPI application (coming soon)
```
